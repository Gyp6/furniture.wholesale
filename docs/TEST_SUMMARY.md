## 3. Відомі особливості та обмеження (Known Issues / Limitations)

З метою дотримання політики прозорості (Transparency Policy), команда документує такі некритичні особливості роботи поточної версії MVP:

1.  **Обмеження Email-сервісу (Resend Sandbox Mode):**
    *   *Проблема:* У режимі розробки при використанні безкоштовного API ключа Resend листи надсилаються тільки на адресу власника акаунту (або примусово перенаправляються в коді на `yanbellq@gmail.com` для запобігання спаму).
    *   *Вплив:* Низький. Листи про реєстрацію чи замовлення логуються в консоль бекенду у режимі розробки, тому реальна доставка не потрібна для локального тестування.
2.  **Залежність Монтування S3 Диска:**
    *   *Проблема:* Команди `make s3-mount` та `make prod-s3-mount` потребують локально встановлених утиліт `rclone` та драйвера `winfsp` для Windows.
    *   *Вплив:* Низький. Це необхідно виключно для візуального перегляду файлів S3 як локального диска `S:\` або `P:\` у провіднику Windows. Завантаження та відображення картинок меблів у браузері працює автоматично через HTTP API LocalStack без монтування диску.
3.  **Неактивні кнопки OAuth провайдерів:**
    *   *Проблема:* Вхід через Google OAuth потребує заповнення реальних `GOOGLE_CLIENT_ID` та `GOOGLE_CLIENT_SECRET` в `.env`. Без них працює тільки стандартна форма логіну/паролю.
    *   *Вплив:* Низький. Тестові доступи (Credentials) надані у файлі README для всіх ролей, що дозволяє повноцінно протестувати систему без налаштування ключів OAuth.
